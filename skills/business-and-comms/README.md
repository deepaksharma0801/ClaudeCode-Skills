# Business & Communication Skills

Skills for status updates, meeting follow-ups, and consistent writing.

- **[weekly-status-update](weekly-status-update)** — Turn git history or notes into an outcome-first weekly update with blockers.
- **[meeting-notes-to-actions](meeting-notes-to-actions)** — Pull decisions, owned and dated action items, and open questions from a transcript.
- **[incident-postmortem](incident-postmortem)** — Write a blameless postmortem with impact, timeline, root cause, and owned action items.
- **[release-notes-writer](release-notes-writer)** — Turn commits and PRs into user-facing release notes, breaking changes first.
