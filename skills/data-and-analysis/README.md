# Data & Analysis Skills

Skills for profiling data, checking queries, and reading experiment results.

- **[csv-data-summarizer](csv-data-summarizer)** — Profile a CSV for columns, distributions, missing data, and correlations in one pass.
- **[sql-query-reviewer](sql-query-reviewer)** — Catch join fan-out, NULL traps, and date-filter bugs, then flag slow patterns.
- **[ab-test-readout](ab-test-readout)** — Sanity-check an experiment, compute lift with confidence intervals, and make a ship call.
- **[metric-definition-writer](metric-definition-writer)** — Turn a vague KPI into a precise definition card with edge cases and reference SQL.
- **[log-triage](log-triage)** — Group log lines into patterns, rank by count and onset, and point to the likely cause.
- **[data-quality-checks](data-quality-checks)** — Design freshness, volume, uniqueness, and integrity tests for a table or pipeline.
- **[chart-critique](chart-critique)** — Catch misleading scales and wrong chart types, then propose a clearer redesign.
- **[cohort-retention-analysis](cohort-retention-analysis)** — Build cohort retention tables without fake drop-off from incomplete periods.
- **[funnel-analysis](funnel-analysis)** — Ordered funnels with conversion windows, the biggest leak, and the segment where it's worst.
