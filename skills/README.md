# Skills

Procedural knowledge for Claude. Each skill lives in its own folder containing a `SKILL.md`
with YAML frontmatter, plus any supporting scripts or reference files.

| Category | Scope |
| --- | --- |
| [`development/`](development) | Coding, debugging, refactoring, build and test workflows |
| [`data-and-analysis/`](data-and-analysis) | Data profiling, research, reporting, notebooks |
| [`business-and-comms/`](business-and-comms) | Writing, branding, internal and external communication |
| [`security-and-qa/`](security-and-qa) | Security review, threat modeling, QA and test strategy |

New skill? Start from [`../templates/SKILL_TEMPLATE.md`](../templates/SKILL_TEMPLATE.md) and read
[`../CONTRIBUTING.md`](../CONTRIBUTING.md).
