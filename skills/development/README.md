# Development Skills

Skills for writing, debugging, and shipping code.

- **[root-cause-debugging](root-cause-debugging)** — Trace a bug backward to the line that first produced the bad state, and fix it there.
- **[safe-refactor](safe-refactor)** — Pin behavior with tests, then refactor in small steps with the suite green after each.
- **[commit-message-writer](commit-message-writer)** — Write a commit message from the staged diff in the repo's existing style.
- **[pr-description-writer](pr-description-writer)** — Write a PR title and description from the actual diff: summary, changes, risk, testing.
- **[codebase-onboarding](codebase-onboarding)** — Map an unfamiliar repo: entry points, one traced flow, architecture, and how to run it.
- **[dockerfile-optimizer](dockerfile-optimizer)** — Rewrite a Dockerfile for cached builds, multi-stage size savings, and a non-root user.
- **[regex-builder](regex-builder)** — Build a regex from a description and prove it against matching and non-matching cases.
- **[api-design-review](api-design-review)** — Review an API design for naming, status codes, errors, pagination, and breaking changes.
- **[performance-investigation](performance-investigation)** — Measure, profile the hot path, and prove each speedup with before/after numbers.
- **[db-migration-safety](db-migration-safety)** — Lint Postgres migrations for locks and breaking changes, then rewrite them as safe steps.
- **[ci-failure-debugger](ci-failure-debugger)** — Find the first real error in a failing CI run, classify it, and fix the cause.
- **[dependency-upgrade-planner](dependency-upgrade-planner)** — Plan major-version upgrades from changelogs and codemods, one verified step at a time.
- **[observability-instrumentation](observability-instrumentation)** — Add structured logs, RED metrics, and OpenTelemetry traces that answer incident questions.
- **[git-recovery](git-recovery)** — Recover lost commits, branches, and stashes with reflog and non-destructive restores.
